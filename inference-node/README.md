# Inference Node Sandbox

A prototype for the "Inference Node" architecture. 
It records every AI inference in real-time, stores them in a JSONL event stream, 
and renders them into beautiful, human-readable Markdown sessions.

## How to Run
1. Open `sandbox.py` in a terminal.
2. Run `python sandbox.py`.
3. It will generate a sample session and print the resulting Markdown.

## Key Files
- `DESIGN.md`: High-level vision.
- `ARCHITECTURE.md`: Technical blueprint.
- `sandbox.py`: The core prototype code.
